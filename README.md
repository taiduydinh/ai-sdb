# Included papers for the AI/ML/DL OSA/SDB review

This repository should store **metadata and official links** for the included papers in the review, not copyrighted PDF files.

## Contents

- `osa_sdb_218_core_papers_download_manifest.csv`: metadata, DOI/official URL, taxonomy groups, and review tags for the 218 core papers.
- `osa_sdb_218_core_papers_official_urls.txt`: one official DOI/publisher link per paper for manual download through institutional access or open-access pages.
- `osa_sdb_core_papers_vosviewer_bibliographic.ris`: RIS file for bibliographic import and VOSviewer.
- `osa_sdb_core_papers_vosviewer_enriched_tags.ris`: RIS file enriched with review-derived tags for term/keyword co-occurrence maps.

## Important copyright note

Do **not** upload full-text PDFs to GitHub unless each PDF is explicitly open access and its license permits redistribution, for example a suitable Creative Commons license. For most publisher PDFs, redistribution on GitHub is not permitted. Use DOI links, official publisher URLs, or open-access landing pages instead.
